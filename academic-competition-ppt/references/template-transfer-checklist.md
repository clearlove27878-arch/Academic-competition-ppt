# Template Transfer Checklist

Use this checklist when generating a deck from a newly supplied template or style reference.

## Style Match

- The generated cover resembles the reference's cover logic, not just its colors.
- Header/footer/navigation behavior matches the reference or the agreed hybrid.
- Title hierarchy, body density, card shapes, line weights, and accents feel consistent.
- Repeated page chrome is stable across the deck.
- Chapter dividers and closing pages use the active template identity.

## Paper Fit

- Paper structure remains primary.
- Original figures/tables are used or faithfully framed when available.
- Equations and regression tables remain readable.
- Long-form 50-70 slide decks have enough micro-page patterns; the template is not stretched into repetitive filler.
- Question-led robustness/model pages remain clear even if the reference uses decorative layouts.

## Transfer Integrity

- Do not claim a style element exists if it was not visible in a small screenshot set.
- Do not permanently overwrite the default style unless the user requested it.
- Do not modify the reference PPT/PPTX.
- If using generated backgrounds, ensure they follow the active template and remain non-evidence assets.

## QA

- Render the output contact sheet.
- Compare at least these pairs: cover-to-cover, chapter-to-chapter, body-to-body, table/figure-to-table/figure, closing-to-closing.
- List visible deviations and whether they were intentional for readability.
