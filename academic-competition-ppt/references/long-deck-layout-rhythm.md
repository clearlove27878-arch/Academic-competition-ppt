# Long Deck Layout Rhythm

Long-form paper decks need page rhythm. Do not solve long content by repeating one layout.

## Chapter Contract

Each major chapter should include at least:

- 1 chapter divider or visual transition page;
- 1 problem/follow-up transition page;
- 2-4 explanation or evidence pages;
- 1 recap, synthesis, or transition page.

For shorter chapters, combine recap with the final evidence page through a bottom takeaway.

## Rhythm Rule

- Every 6-8 pages must introduce a visual change.
- Adjacent 5 pages must not use exactly the same layout.
- Alternate between narrative pages, mechanism diagrams, formulas, tables, evidence close-ups, dense cards, and synthesis pages.

## Visual Change Types

- Chapter divider with deep green banner.
- Question transition page.
- Mechanism diagram page.
- Formula decomposition page.
- Table + interpretation page.
- Source-anchor paragraph page.
- Recap / logic-chain return page.
- Contrast page: wrong intuition vs paper logic.

## Anti-Mechanical Split Rule

Do not split one original paragraph into multiple pages unless each page has a distinct cognition task and a distinct layout role.

Every added page must answer:

- What source idea does this page carry?
- What does the audience understand after this page?
- How does the layout differ from nearby pages?
