# Visual Density Rules

Use this before building or reviewing any default long-form paper deck. Long-form does not mean sparse. The page should feel full, readable, and designed.

## Density Target

- Ordinary content slide visual fill: 65%-85%.
- Below 60% is a warning state.
- Sparse pages must add meaningful content or structure: source-driven paragraph, explanation box, mechanism card, bottom takeaway, side note, background decoration, figure/table, or transition object.
- Do not fill space with random icons, huge decorative shapes, or generic slogans.

## Information Density

Default long-form paper slides should carry:

- 1 compressed main title.
- 1 subtitle or page question.
- 1-2 explanatory paragraphs, usually 50-120 Chinese characters each.
- 1 paper object: source paraphrase, definition, variable, model, formula, table, figure, mechanism, expected test, or boundary statement.
- 1 bottom takeaway bar.

## Preferred Layouts

Use layouts that create a strong body, not floating fragments:

- left narrative paragraph + right mechanism/object;
- top formula panel + lower explanation and boundary;
- central mechanism diagram + side explanation cards;
- three dense cards + bottom takeaway;
- table + right-side result translation;
- source paragraph + keyword tags + transition line;
- evidence object dominant + compact interpretation panel.

## Sparse Page Fixes

If a page is underfilled:

1. Add faithful source paraphrase before generic explanation.
2. Add a paper object or crop/table/variable card.
3. Add a bottom takeaway with a real conclusion.
4. Add subtle background decoration or bottom color band.
5. Split only when the page is crowded, not when it is sparse.

## Anti-Patterns

- One short sentence floating in a large white slide.
- Tiny formula panel with large empty margins.
- Three small cards centered with no bottom takeaway.
- Weak title/header and no footer.
- Repeated card grid for many consecutive pages.
