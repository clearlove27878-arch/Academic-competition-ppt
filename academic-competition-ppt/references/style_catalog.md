# PPT Style Catalog

Use this catalog only when Style Extension Mode is active. If the user does not specify a style, template, or request for style options, use `style_01_default_academic.md` visually while keeping Long-form Paper Presentation Mode as the content default.

## Style 01: Default Refined Teal Academic / 默认精修深青绿学术风

适用场景：
- 课程报告
- 学术竞赛
- 长页数论文汇报
- 真实论文讲解
- 社科、经管、政策分析类 PPT

特点：
- 信息密度较高，默认服务 30-70 页论文讲解
- 结构清晰
- 标题明确
- 白/浅灰正文页，深青绿顶栏，黄色当前章节 chip
- 导航栏稳定清晰，有章节定位感，视觉尽可能饱满
- 左侧短标题约 16-20 pt，active 章节 chip 约 12-16 pt，inactive chip 约 10-14 pt 且低约 2 pt
- 轻卡片/公式面板、底栏或 corner chrome、低饱和渐变底栏
- 兼容克制浅纹理和适度更明显的背景装饰、深青绿标题条
- 配色稳健，适合长页数阅读
- 政策建议不过度具体

调用规则：
- 用户未指定风格时，始终使用该视觉风格。
- 该风格不改变默认长页数论文汇报内容范式。

Style card: `style_01_default_academic.md`

## Style 02: Deep Blue Policy / 深蓝政策研究风

适用场景：
- 绿色金融
- 环境规制
- 数字经济
- 政策评估
- 实证论文汇报

视觉特征：
- 深蓝、蓝黑、灰白为主
- 适合半透明卡片、细线、数据图表
- 风格正式、稳健、学术感强

Style card: `style_02_deep_blue_policy.md`

## Style 03: Minimal White Research / 极简白学术风

适用场景：
- 论文答辩
- 文献综述
- 理论机制分析
- 研究设计展示

视觉特征：
- 白底、浅灰、黑字、少量强调色
- 留白较多
- 更重视逻辑层级和图表可读性

Style card: `style_03_minimal_white_research.md`

## Style 04: Red Gold Competition / 红金竞赛风

适用场景：
- 创新创业竞赛
- 挑战杯
- 成果展示
- 党建/政策导向项目

视觉特征：
- 红色、金色、米白为主
- 更强的竞赛感和正式感
- 适合封面、成果页、总结页强化视觉冲击

Style card: `style_04_red_gold_competition.md`

## Style 05: Green Development / 绿色发展风

适用场景：
- 绿色金融
- 环境经济学
- 碳减排
- 生态文明
- 可持续发展

视觉特征：
- 绿色、青绿、浅灰、白色为主
- 可使用生态线条、渐变色块、地图/碳排/能源图形
- 注意避免过度环保宣传海报化，保持学术感

Style card: `style_05_green_development.md`

## Style 06: Dark Tech / 深色科技风

适用场景：
- 数字经济
- 人工智能
- 金融科技
- 平台经济
- 数据治理

视觉特征：
- 深色背景
- 蓝紫、青蓝、荧光线条作为点缀
- 适合数据流、平台、算法、网络结构类主题
- 注意正文可读性，不能做成纯视觉海报

Style card: `style_06_dark_tech.md`

## Style 07: Green Fresh Pastoral / 绿色清新田园简约风

适用场景：
- 乡村振兴
- 农业经济
- 绿色发展课程报告
- 环境经济学研究计划
- 用户明确要求白底、绿色清新、田园、简约或精细顶部导航

视觉特征：
- 白/浅灰正文页
- 深绿主色、少量黄色强调
- 当前章节导航放大、加粗、深绿、短下划线
- 左上右指向双三角识别符
- 无底部导航矩形框

调用规则：
- 这是可选扩展风格，不是默认风格。
- 用户明确要求绿色清新、田园简约、白底深绿精细导航，或引用对应模板时使用。

Style card: `style_07_green_fresh_pastoral.md`
