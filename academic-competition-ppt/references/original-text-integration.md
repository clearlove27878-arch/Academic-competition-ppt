# Original Text Integration

Long-form paper decks must be source-driven. AI writing is for explanation, transition, and presentation adaptation; it must not replace the paper's own ideas.

## Source Share Rule

- Each major chapter should derive 40%-60% of body content from original anchors, original viewpoints, or faithful paraphrases.
- Every ordinary page should include at least one original thought object:
  - faithful paraphrase;
  - variable definition;
  - model setting;
  - measurement rule;
  - mechanism judgment;
  - result interpretation;
  - research boundary;
  - source table/figure/formula.

## Conversion Path

Default path:

`original viewpoint -> faithful paraphrase -> presentation explanation -> page takeaway`.

Do not start with generic framework language and then sprinkle source terms.

## What AI Adds

AI may add:

- plain-language explanation;
- logical bridge;
- transition question;
- audience-facing analogy;
- page takeaway;
- structure and hierarchy.

AI must not invent:

- coefficients;
- sample sizes;
- empirical findings;
- policy events;
- mechanisms absent from the source;
- over-specific policy recommendations.

## Framework Language Limit

Phrases such as `本页回答什么问题`, `经济含义`, `解释边界`, `识别逻辑` are useful labels, but they cannot be the main content. They must be paired with source-specific substance.

## Slide Inventory Requirement

Before building, record:

`page -> source anchor/thought object -> faithful paraphrase -> explanation role -> paper object -> takeaway`.
