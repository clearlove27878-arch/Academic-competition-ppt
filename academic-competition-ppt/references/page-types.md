# Page Types

Use these page types as the deck library. Default output is a long-form paper presentation: 30-45 slides for ordinary papers, 40-60 for empirical deep explanation, and 50-70 for complex methods, formulas, or literature seminars. Short 15-20 slide decks are explicit summary variants only.

## Default Long-Form 30-70 Slide Structure

Use this by default. The goal is coverage and explanation, not compression and not mechanical splitting. Long-form decks must still include strong navigation, chapter dividers, bottom takeaway bars, background identity, stage recaps, and logic-chain return pages unless the user explicitly requests ordinary courseware.

| Range | Chapter | Typical Pages |
|---:|---|---|
| 1-3 | Opening | cover, reality paradox, table of contents or research-chain map |
| 4-8 | Problem Chain | background tension, wrong intuition, research question, literature gap |
| 9-15 | Concept Chain | definitions, measurement, theoretical foundation, hypotheses |
| 16-25 | Model / Measurement | formula walkthrough, symbol decoder, variable construction, method rationale |
| 26-34 | Data / Identification | data source, sample, descriptive logic, identification threat, model boundary |
| 35-45 | Main Evidence / Expected Tests | baseline table or planned test, coefficient meaning, result translation |
| 46-55 | Mechanism / Heterogeneity | pathway tests, subgroup stories, interaction or boundary logic |
| 56-64 | Robustness / Endogeneity | doubts, alternative measures, placebo, lag, IV/DID/event study checks |
| 65-69 | Contribution / Implications | academic contribution, policy/method implications, limitations |
| 70 | Closing | Q&A |

Adjust within the default ranges according to source complexity. Research plans may stop at 28-45 slides while preserving planned-test language.

Each major chapter should include at least one chapter/transition page, one follow-up question page, two to four explanation/evidence pages, and one recap or transition takeaway. Ordinary content pages should include source-driven paragraphs, a paper object, visible header/navigation, and bottom takeaway chrome.

## Short / Explicit Summary Variant: 20-Slide Competition Structure

Use only when the user explicitly asks for a concise, short, roadshow, speed-defense, or 15-20 slide version.

| # | Page Type | Purpose | Proof Object |
|---:|---|---|---|
| 1 | Cover | Contest identity and research title | Background image + title |
| 2 | Research Puzzle Hook | Why the question matters | Contradiction cards / policy fact |
| 3 | Policy Background | Policy context and timeline | Timeline + policy milestones |
| 4 | Literature Review | Existing research streams | 3-4 literature cards |
| 5 | Research Gap and Contribution | What the paper adds | Contribution ladder / three cards |
| 6 | Theoretical Foundation | Core theory | Theory blocks / assumptions |
| 7 | Mechanism Framework | Causal chain | Editable mechanism diagram |
| 8 | Hypotheses | H1-H3 or H4 structure | Hypothesis cards |
| 9 | Research Design | Identification and model | Equation + DID setup |
| 10 | Sample and Data | Sample, period, data source | Dataset cards / map / sample table |
| 11 | Variable Definitions | Variables and measurement | Variable table |
| 12 | Baseline Regression | Main result | Regression table + highlighted coefficient |
| 13 | Parallel Trend / Dynamic Effect | Identification validity | Event-study plot placeholder |
| 14 | Robustness I | Method robustness | Result cards + table/plot |
| 15 | Robustness II | Alternative checks | Multi-panel evidence |
| 16 | Mechanism Test | Why it works | Path diagram + coefficient cards |
| 17 | Heterogeneity Analysis | Where it works | Subgroup cards / heatmap |
| 18 | Integrated Findings | Synthesize all evidence | Full mechanism map |
| 19 | Policy Recommendations | Actionable implications | 4 recommendation cards |
| 20 | Thanks / Q&A | Closing | Title + contest line |

## Short / Explicit Summary Variant: 15-Slide Non-Repeating Alternative

Use only when the user explicitly asks for a very concise deck or when the source has too little material for a longer explanation:

1. Cover
2. Research Puzzle Hook
3. Background + Literature Gap
4. Contributions
5. Theory and Hypotheses
6. Mechanism Framework
7. Research Design
8. Data and Variables
9. Baseline Regression
10. Dynamic/Parallel Trend
11. Robustness
12. Mechanism Test
13. Heterogeneity or Further Discussion
14. Conclusions and Policy Suggestions
15. Thanks / Q&A

## Expanded Long-Form 50-70 Slide Structure

Use this by default for detailed empirical papers, 40-page-plus reports, complex formulas, dense literature seminars, or when the source has many tables/tests. The goal is coverage and explanation, not compression.

### Default 60-Slide Structure

| Range | Chapter | Typical Pages |
|---:|---|---|
| 1-3 | Opening | Cover, hook analogy/puzzle, table of contents |
| 4 | Logic Chain | full research chain / chapter roadmap |
| 5-9 | Research Motivation | background, policy/market context, core contradiction, research question, stage recap |
| 10 | Chapter Divider | theory/model entry |
| 11-16 | Concept and Theory | key concepts, formal definitions, intuition, theoretical proposition, hypotheses |
| 17-26 | Model and Measurement | formula walkthrough, symbol definitions, decomposition logic, estimation challenge, method choice, stage recap |
| 27 | Chapter Divider | data/design entry |
| 28-34 | Data and Variables | data source, sample period, sample filter, variable construction, descriptive statistics |
| 35-42 | Main Evidence | baseline table, figure reading, coefficient meaning, main metric, first interpretation |
| 43 | Stage Recap | what main evidence has proven |
| 44-50 | Extensions and Robustness | alternative sample, alternative database, placebo, lag structure, sensitivity checks |
| 51-56 | Mechanisms and Heterogeneity | mediator/pathway, subgroup evidence, threshold/interaction, mechanism synthesis |
| 57 | Logic Chain Return | map evidence back to the full causal chain |
| 58-59 | Implications | academic meaning, policy or market implication, final conclusion |
| 60 | Closing | Thanks / Q&A |

### 50-Slide Moderate Long Form

Use if the paper is detailed but does not need the full 60-70 slide treatment:

- Opening: 3
- Motivation/literature: 6
- Theory/model: 10
- Data/variables: 7
- Main results: 9
- Robustness/mechanisms/heterogeneity: 11
- Conclusion/thanks: 4

### 70-Slide Expanded Long Form

Use if the paper has many formulas, figures, or tests:

- Opening: 3
- Motivation/literature: 8
- Theory/concepts: 10
- Model/formula derivation: 14
- Data/variables/measurement: 10
- Main results: 10
- Robustness battery: 8
- Mechanism/heterogeneity: 5
- Conclusion/thanks: 2

## Long-Form Micro Page Types

These are repeatable, but each instance must carry new content.

| Micro Type | Use |
|---|---|
| Chapter Divider | Deep teal competition-style transition page for a new chapter |
| Logic Chain Map | Full causal/research chain with current segment highlighted |
| Breadcrumb Content Page | Ordinary content page with top nav and small current-step breadcrumb |
| Stage Recap | 3-5 bullets summarizing what has been proven before moving on |
| Analogy Hook | Translate the identification or bias problem into a memorable story |
| Concept Definition | Define one construct such as tilt, active share, treatment, or exposure |
| Symbol Decoder | Explain every symbol in one equation |
| Formula Step | Move from one equation line to the next |
| Naive Method Failure | Explain why OLS/t-test/simple comparison is biased |
| Estimator Rationale | Explain Probit, Heckman, DID, IV, PSM, threshold, or mediation choice |
| Data Pipeline | Show sample construction and exclusions |
| Variable Card | One dependent/core/control variable group |
| Figure Walkthrough | One chart plus "how to read it" |
| Table Walkthrough | One regression table/crop plus highlighted coefficient |
| Evidence Dominant Figure | Original paper figure/table takes most of the content area; explanation is a short side or bottom callout |
| Evidence Close-Up | A cropped key panel, key rows, or key columns from an original table/figure for readability |
| Coefficient Interpretation | Translate coefficient into economic meaning |
| Robustness Doubt-Test | One doubt and one robustness response |
| Alternative Measure | Replace database/variable/model and compare results |
| Mechanism Path | One pathway or mediator at a time |
| Heterogeneity Slice | One subgroup comparison at a time |
| Section Recap | 3 bullets summarizing what was proven before moving on |

## Ordinary Courseware Variant

Use only when the user explicitly asks not to use competition mode.

Differences:

- Keep the same 50/60/70 slide logic and micro-page types.
- Use simpler white/green lecture pages.
- Replace the competition nav bar with a light header and page number.
- Use fewer chapter divider pages.
- Keep formulas, tables, and figures larger and more lecture-like.

Even in courseware mode, do not collapse multiple formula steps or empirical tests onto one unreadable slide.

## Page Type Details

### Cover

- Use deep teal full-slide atmosphere.
- Put contest name small at top.
- Put research title centered, heavy Song style, white or warm white gradient.
- Add author/team/date line near bottom.
- Use a landscape, university, policy, city, or green finance visual only if available; otherwise use abstract teal wave.

### Research Puzzle Hook

- Use a question-style title.
- Show two opposing expectations or facts.
- Use gold highlight for the puzzle term.
- Keep text compact; this page should be memorable.

### Policy Background

- Use timeline or 2x2 policy cards.
- Include policy names, years, pilot region, or institutional context.
- Do not overfill with paragraphs.

### Literature Review

- Use 3-4 cards: information disclosure, green finance policy, environmental regulation, capital market reaction, etc.
- Each card: literature stream + limitation.
- End with a small gap statement.

### Research Gap and Contribution

- Use a "本文边际贡献" page.
- Prefer 3 contributions: theory, empirical identification, policy implication.
- Use teal cards with gold numbering.

### Theoretical Foundation / Model

- Use equations only when they explain the mechanism.
- Put equations in white panels.
- Pair each equation block with a plain-language interpretation.

### Mechanism Framework

- Use editable arrows and nodes.
- Typical chain: policy shock -> resource allocation / innovation / financing constraint / information disclosure -> enterprise or city behavior -> outcome.
- Use teal nodes and gold active mechanism markers.

### Research Design

- Show model equation prominently.
- Include treatment/control, fixed effects, time window, clustering, and controls.
- Make `DID` or core policy variable visually prominent.

### Sample and Data

- Use cards for sample period, data source, sample size, treatment/control, exclusions.
- Add map or dataset table only if useful.

### Variable Definitions

- Native table with columns: variable type, symbol, definition, source.
- Highlight explained variable and core explanatory variable.

### Baseline Regression

- Use a cropped or simplified table, but keep the original paper evidence large enough to read.
- Highlight the core coefficient with a gold callout.
- Add interpretation: direction, significance, economic meaning.
- If the full table is too dense, use two slides: full-table context first, then key-column/key-row close-up.

### Parallel Trend / Dynamic Effect

- Use the event-study plot as the proof object.
- Add left/right interpretation cards: before-policy validity and after-policy effect.
- Crop away irrelevant PDF margins and scale the plot to be the dominant visual object.

### Robustness

- Split if there are multiple methods: placebo, lagged variable, alternative dependent variable, PSM-DID, winsorization, excluding samples.
- Each page should say what risk the test addresses.
- Robustness table pages should prioritize the original result table/crop. Use short problem-oriented titles and concise explanation beside or below the enlarged evidence.

### Mechanism Test

- Use a path diagram plus coefficient cards.
- Do not show all columns if it kills readability.
- Label mediators clearly.
- When the paper's original mechanism table is the proof object, enlarge the table/crop first and use the mechanism diagram only as a supporting element or a separate synthesis page.

### Heterogeneity Analysis

- Use subgroup cards: region, ownership, industry, resource city, transparency, investor type, etc.
- Show direction and relative strength.

### Integrated Findings

- Reconstruct the whole causal story in one page.
- Use this before conclusion/policy pages to help judges remember the logic.

### Policy Recommendations

- Use 4 cards or a 2x2 grid.
- Recommendations must connect to findings, not generic slogans.

### Thanks / Q&A

- Return to cover visual identity.
- Keep one title line and one subtitle line.
- Include "谢谢各位评委老师批评指正" when contest-facing.
