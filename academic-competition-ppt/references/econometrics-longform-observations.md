## Long-Form Story Rhythm

The reference uses a gradual technical teaching rhythm:

1. Start with a memorable analogy or paradox.
2. Show table of contents early.
3. Define the central concept before presenting formulas.
4. Split formulas into several slides, explaining each symbol.
5. Use intuitive examples before formal derivation.
6. Explain estimation problems before giving the method.
7. Separate data source, sample filtering, and variable construction.
8. Present figures/tables one at a time with plain-language interpretation.
9. Use many robustness slides; each slide answers one doubt.
10. End with synthesis, implications, and thanks.

## Micro-Page Patterns

Use these patterns in 50-70 slide decks:

- **Analogy Hook:** story/paradox -> research logic.
- **Concept Definition:** one concept, one formula, one plain-language explanation.
- **Formula Symbols:** break a formula into variables and meanings.
- **Formula Step:** derive one line or transformation per slide.
- **Bias Warning:** show why a naive method fails.
- **Method Choice:** problem -> estimation method -> why it solves the problem.
- **Two-Step Decision:** probability stage plus intensity/weight stage.
- **Data Source:** dataset identity, sample period, coverage, exclusions.
- **Sample Filter:** inclusion/exclusion flow.
- **Variable Construction:** variable formula plus operational definition.
- **Figure Reading:** one chart with 2-3 interpretation bullets.
- **Table Reading:** one table or cropped table with highlighted coefficient.
- **Result Interpretation:** what the coefficient means economically.
- **Robustness Doubt:** a possible critique and the test that addresses it.
- **Mechanism Explanation:** path or mediator, not just regression output.
- **Comparison Slide:** baseline vs alternative database/model/sample.
- **Implication Slide:** academic and policy meaning.
- **Section Recap:** one sentence per result before moving to the next chapter.

## Long-Form Page Count Guidance

For a 40-page-plus empirical paper:

- 50 slides: detailed but controlled; good for 25-35 minute reports.
- 60 slides: default when the user says every detail matters.
