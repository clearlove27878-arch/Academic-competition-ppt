# Narrative Expansion

Use this to expand a short paper outline into a long-form paper presentation. Do not allocate slides mechanically by section heading. Allocate slides by audience cognition load.

## Expansion Pattern

For each paper chapter or outline heading, build:

`original heading -> chapter core question -> why it matters -> common intuition or wrong approach -> paper's treatment -> core concept explanation -> formula/variable/model explanation -> economic meaning -> limitation/boundary -> transition to next section`.

Each element can become one slide only if it carries a distinct cognition task, a source thought object, and a visible layout role. Do not create pages that only restate `this page answers...`.

## Cognitive Cut Rules

Split pages when:

- A concept needs definition and measurement.
- A formula needs symbol decoding and coefficient interpretation.
- A model choice needs a naive-method contrast.
- A table needs both context and key-row/key-column close-up.
- A mechanism has multiple pathways.
- A robustness section answers multiple doubts.
- A result needs translation, theory return, and next question.

Do not split when the extra page would only repeat the same card grid with weaker wording.

Do not split if the result is sparse. If a page is added, it should become fuller through source paraphrase, paragraph explanation, paper object, bottom takeaway, and visual chrome.

## Long-Form Rhythm

Use a rhythm such as:

`question transition -> explanation page -> paper object page -> interpretation page -> recap/next question`.

Every 6-8 pages, add a change of rhythm: stage recap, logic-chain return, evidence close-up, formula breakdown, comparison page, chapter divider, deep green banner, or synthesis page. Adjacent 5 pages must not use the exact same layout.

## Research Plan Expansion

For a research plan that has only an 18-slide skeleton, expand into 28-45 slides by adding:

- Why the problem matters and what intuition may be wrong.
- Definitions and measurement pages for each key variable.
- Model purpose and coefficient interpretation pages.
- Expected-test pages that say what question each planned test will answer.
- Endogeneity/robustness threat pages.
- Limitations and implementation schedule pages.

Never present expected tests as completed empirical results.

Use the earlier green academic version as visual baseline when expanding research-plan skeletons: keep refined navigation, bottom takeaway bars, subtle background decoration, and dense academic cards. Do not imitate sparse pages with weak navigation and large blank areas.
