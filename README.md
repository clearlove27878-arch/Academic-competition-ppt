# Academic Competition PPT Skill

一个用于生成中文学术论文汇报 / 竞赛答辩 PPT 的 Codex skill。

默认风格偏学术竞赛：深青绿主视觉、金色点缀、顶部导航栏、圆角内容卡片、原文图表重点呈现，适合经济学、绿色金融、环境规制、实证论文汇报等场景。

## 功能

- 解析论文结构：引言、理论机制、实证设计、基准回归、稳健性、机制检验、异质性、结论等。
- 生成可编辑 PPTX，而不是整页截图。
- 支持 20 页左右精讲版，也支持 50-70 页长篇论文汇报。
- 优先放大呈现论文原图、原表，裁剪空白但保持比例。
- 可学习用户提供的新 PPT / 模板 / 截图风格。

## 安装

将 `academic-competition-ppt` 文件夹放入 Codex skills 目录：

```text
C:\Users\<你的用户名>\.codex\skills\
```

放置后路径应类似：

```text
C:\Users\<你的用户名>\.codex\skills\academic-competition-ppt\SKILL.md
```

## 使用示例

```text
使用 $Academic Competition PPT，读取这篇论文，生成一份 30 页左右的学术竞赛风格 PPT。
```

```text
按这个 PPT 的风格来，先学习模板，再根据我的论文生成汇报 PPT。
```

## 说明

该 skill 主要服务于中文学术论文汇报，尤其适合经济学、金融学、环境经济、绿色金融和计量实证类论文。
